Cos'è AXL

AXL è un linguaggio di programmazione generale progettato per agenti AI e modelli di linguaggio. Non è un framework — è un linguaggio completo con parser, type checker, e interpreter.


Il formato sorgente è compatto e deterministico, ottimizzato per la generazione e lettura da parte di LLM, non per la scrittura manuale.


Linguaggio Generale

Può costruire qualsiasi cosa: backend, API, frontend, CLI, database, LLM applications

Agent-Native

Formato compatto RPN che riduce i token del 69% rispetto a linguaggi tradizionali

crm.axl 
// Connessione al database
10|db|"/tmp/crm.db",!db_connect/1|s;

// Creazione tabella customers
10|s1|$db,
  "CREATE TABLE customers (...)",
  !db_execute/2|s;

// Inserimento dati
10|i1|$db,"customers",
  "name","Alice",
  "email","alice@acme.com",
  %2, !db_insert/3|s;

// Avvio server con API CRUD
10|tables|"customers",~1;
10|srv|"0.0.0.0:8080",
  "build/crm",$db,$tables,
  !axl_server_start/4|s;

Sintassi RPN

AXL usa Reverse Polish Notation — gli operandi precedono l'operatore. Questo formato è ideale per i LLM perché elimina ambiguità e parentesi.


Anatomia di un frame AXL

Opcode 10 | nome_var | "valore" | !primitiva/1 | s
binding target expression tool call end

Token Significato Esempio
#123 Intero #42
"testo" Stringa "ciao"
$nome Variabile $db
@chiave Recall memoria @config
!nome/arity Chiamata primitiva !db_connect/1
^nome/arity Chiamata funzione ^my_func/2
~N Costruzione lista "a","b",~2
%N Costruzione mappa "k","v",%1

Opcode del Linguaggio

Ogni istruzione AXL inizia con un opcode numerico che identifica il tipo di operazione. I frame sono separati da ;.


Opcode Tipo
10Binding (let)
11Return
12Emit (output)
20Memory Write
21Forget
30If
31Else
32While
40Function
50Agent
51Workflow
99End Block
Esempi di opcode 
// Binding: 10|target|expr|s
10|x|#42|s;

// Emit: 12|expr
12|"Hello";

// If: 30|cond ... 99
30|$x,#5,G;
  12|"grande";
99;

// Function: 40|name|params|ret ... 99
40|add|a:i,b:i|i;
  11|$a,$b,+;
99;

// Agent: 50|name|tools ... 99
50|assistant|db_query,llm_reason;
  10|r|"SELECT *",
    !db_query/2|s;
99;

Sistema di Tipi

AXL ha un sistema di tipi statico con type checking a compile-time. I tipi sono espressi con codici singoli per compattezza.


Codice Tipo Esempio
iInteger#42
sString"hello"
bBoolean?1 / ?0
aAnytipo dinamico
liList<Int>~3
lsList<String>~2
msMap<String,Any>%2

Errori catturati a compile-time, non a runtime

Sistema di Memoria

AXL ha un sistema di memoria persistente con TTL, confidence score, e scope. Gli agenti possono salvare e recuperare conoscenze.


Write
Salvataggio
// Salva in memoria
20|"user:alice",
  $userData;

// Con metadata
20|"config",
  $config,
  #95,     // confidence
  #3600,   // TTL (sec)
  "program";
Read
Recupero
// Recall da memoria
10|user|
  @"user:alice"|s;

// Forget (cancella)
21|"user:alice";

// La memoria è scoped:
// session:X  → solo sessione
// project:X  → persistente
// agent:X    → per agente

Integrazione LLM

AXL ha primitive native per interagire con modelli di linguaggio. Non servono librerie esterne o API client — tutto è integrato nel linguaggio.


Primitiva Arità Descrizione
!llm_generate/22Genera testo da prompt
!llm_reason/22Reasoning con chain-of-thought
!llm_classify/22Classifica testo in categorie
!llm_extract/22Estrae informazioni strutturate
!llm_embed/11Genera embedding vettoriale
!llm_similarity/22Cosine similarity tra embedding
LLM in AXL 
// Reasoning
10|analysis|
  "Analizza questo cliente: ",
  $customerName,
  +,
  !llm_reason/2|s;

// Classificazione
10|category|
  $emailText,
  "spam,urgent,normal",
  !llm_classify/2|s;

// Estrazione dati
10|entities|
  $document,
  "name,email,company",
  !llm_extract/2|s;

// Embedding + Similarity
10|vec1|$text1,!
  llm_embed/1|s;
10|sim|$vec1,$vec2,
  !llm_similarity/2|s;

Sistema di Agenti

AXL supporta agenti come first-class citizen con tool grants, memoria dedicata, e comunicazione inter-agente


Agenti e Workflow

  // Goal dell'agente
  10|leads|"SELECT * FROM leads WHERE status='hot'",
    !db_query/2|s;

  // Analisi con LLM
  10|analysis|"Prioritize these leads: ",$leads,+,
    !llm_reason/2|s;

  12|$analysis;
99;

// Workflow multi-step
51|sales_pipeline;
  52|sales_agent;    // Run agent
  52|report_agent;   // Run another
99;
