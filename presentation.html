Cos'è AXL?

AXL è un linguaggio di programmazione generale progettato specificamente per agenti AI e modelli di linguaggio.


Non è un framework CRM, non è un tool specifico — è un linguaggio completo con parser, interpreter, e 194 primitive che wrappano tutto ciò che Rust può fare.


🎯

Agent-Native

Progettato per LLM, non per umani. Formato compatto RPN ottimizzato per token.

⚡

Generale

Può costruire qualsiasi cosa: backend, API, frontend, CLI, database, LLM apps.

crm.axl — 15 righe per un CRM completo 
// Connessione database
10|db|"/tmp/crm.db",!db_connect/1|s;

// Creazione tabelle
10|s1|$db,"CREATE TABLE customers (...)",
  !db_execute/2|s;

// Dati seed
10|i1|$db,"customers",
  "name","Alice",
  "email","alice@acme.com",
  %2, !db_insert/3|s;

// Avvio server con API
10|tables|"customers","leads",~2;
10|result|"0.0.0.0:8080",
  "build/crm",$db,$tables,
  !axl_server_start/4|s;

Come Funziona

AXL usa un formato compatto RPN (Reverse Polish Notation) ottimizzato per la generazione da parte di LLM.


📦

Primitive Native

194 primitive per I/O, DB, HTTP, Crypto, LLM, Text, Math, System

🔧

Runtime Rust

Performance native, memory safety, compilazione AOT

🤖

LLM Integration

Primitivi nativi per reasoning, classification, extraction
