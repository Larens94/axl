  effect db.write

Costruzione verificata · UI

La UI è una porta, non un preset chiuso.

Una skill compatibile può sostituire il renderer predefinito senza modificare il blueprint.

capacity CustomerRow
  op render Customer -> UI

skill DefaultCustomerRow provides CustomerRow
  native react crm::DefaultCustomerRow

blueprint CustomerList
  slot table.row: CustomerRow = DefaultCustomerRow
Cosa controlla oggi

Il compilatore verifica il grafo prima dei target.

✓Tipi, entità, capacity e riferimenti generici.
✓Compatibilità tra porta e provider.
✓Porte obbligatorie non collegate, con candidati di riparazione.
✓Round-trip deterministico tra Graph IR e Packed IR.
×Non verifica ancora l'ABI della funzione Rust o del componente React.
Output reale dell'esperimento

Contratti per quattro mondi.

Rust

Strutture dati e trait delle capacity.

React

Registry dei riferimenti slot.

SQL

DDL iniziale delle entità.

Agenti

Manifest di belief, goal e plan.

Graph IR

JSON esplicito e canonico.

Packed IR

Frame opcode reversibili.

Confine onesto

È un linguaggio sperimentale funzionante. Non ancora un generatore full-stack.

Funziona oggi

Parser, analyzer, formatter, Graph IR, Packed IR, diagnostica, porte tipizzate e adapter dei target.

Prossimo gate

Una vertical slice eseguibile: handler Rust, persistenza SQL e componente React collegati dal grafo esistente.

`if`, `else`, cicli, esecuzione dei contratti e runtime degli agenti non sono ancora sintassi o comportamento AXL implementati.
