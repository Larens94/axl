Il principio non negoziabile

Ogni blocco ha porte aperte.

Capacity

Descrive cosa serve, senza scegliere come viene implementato.

Skill

Collega una capacity a Rust, React, SQL, AI, IoT o WASM.

Surface

Input, slot, hook, parametri, azioni e policy restano personalizzabili.

Compatto, ma leggibile

Descrivere il collegamento.

Il codice applicativo resta AXL. Se manca una primitiva, l’agente si ferma e segnala il punto esatto.

capacity MovementStore
  op save Movement -> Result<Movement>

skill DurableStore provides MovementStore
  native rust axl::store::sqlite
  config path: text = "./data.db"

flow Save Movement -> Result<Movement>
  in store: MovementStore = DurableStore
  call saved = store.save(input)?
  return saved

Come devono lavorare gli agenti

Un protocollo comune.
Zero scorciatoie.

1Partire da un esempio AXL che non compila o non gira.
2Implementare una primitiva generale con tutte le porte aperte.
3Se manca qualcosa, fermarsi e segnalarlo. Mai spostare la logica applicativa in Rust o React.
4Chiudere con test positivo, negativo, round trip, schema, docs e film/presentazione aggiornati.
