Esempi AXL

Tutti gli esempi sono scritti in AXL e eseguiti dall'interpreter.

1. Hello World

2;12|"Hello World from AXL!"

Esecuzione: axl run hello.axl

Output: Hello World from AXL!

2. Variabili e Binding

2;10|x|#42|is;10|name|"AXL"|s;12|$x;12|$name

Output: 42 + AXL

3. Text Operations

2;10|upper|"hello world",!text_upper/1|s;12|$upper
10|words|"a,b,c",!text_split/2,","|s;12|$words

Output: HELLO WORLD + ["a", "b", "c"]

4. Math

2;10|sum|#10,#5,!math_add/2|s;12|$sum
10|prod|#6,#7,!math_mul/2|s;12|$prod

Output: 15 + 42

5. Crypto

2;10|hash|"AXL",!hash_sha256/1|s;12|$hash
10|b64|"hello",!encode_base64/1|s;12|$b64

Output: SHA-256 hash + aGVsbG8=

6. JSON

2;10|data|'{"name":"AXL","version":3}',!json_parse/1|s;12|$data

Output: {"name":"AXL","version":3}

7. File I/O

2;10|w|"/tmp/test.txt","Hello!",!file_write/2|s;12|$w
10|c|"/tmp/test.txt",!file_read/1|s;12|$c

Output: true + Hello!

8. System

2;10|host|!sys_hostname/0|s;12|$host
10|os|!sys_os/0|s;12|$os
10|ts|!time_now/0|s;12|$ts

9. LLM Reasoning

2;10|reason|"step by step","What is 2+2?",!llm_reason/2|s;12|$reason

Output: Chain-of-thought analysis di MiMo

10. LLM Classification

2;10|cat|"Classify this","Rust is great for systems","tech,science,general",!llm_classify/3|s;12|$cat

Output: tech

11. Database

2;10|db|":memory:",!db_connect/1|s;12|$db

Output: db_:memory_

12. Agent + Workflow

2;50|my_agent|;12|"Agent executed";99;52|my_agent;12|"Done"

Output: Agent executed + Done
