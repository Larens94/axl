AXL Documentation v3.0

Linguaggio di programmazione per agenti che wrappa Rust

1. Hello World

Programma AXL base che emette un messaggio:

2;12|"Hello World from AXL!"

Esecuzione:

$ axl run hello.axl
Hello World from AXL!

2. Variabili e Binding

Binding con tipo opzionale:

2;10|x|#42|is;10|name|"AXL"|s;12|$x;12|$name

Output:

42
AXL

3. Primitiva Native — Text

Elaborazione testo con primitive Rust:

2
# Text upper
10|upper|"hello world",!text_upper/1|s;12|$upper;

# Text lower
10|lower|"HELLO WORLD",!text_lower/1|s;12|$lower;

# Text split
10|words|"a,b,c",!text_split/2,","|s;12|$words;

# Text contains
10|has|"hello",!text_contains/2,"hell"|s;12|$has;

Output:

HELLO WORLD
hello world
["a", "b", "c"]
true

  99;

50|analysis_agent|classify_content;

    11|$category;
  99;

Esecuzione

# Compila ed esegui
$ cargo build --workspace
$ cargo run -p axl-cli -- run examples/ai-platform/platform.axl

# Esegui con memory persistente
$ cargo run -p axl-cli -- run program.axl --memory db.sqlite

# Compila a JSON IR
$ cargo run -p axl-cli -- compile program.axl -o program.json
