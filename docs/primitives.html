Primitiva Native — 216 Primitiva

Ogni capability di Rust è esponibile come primitiva AXL. Gli agenti combinano queste primitive per costruire qualsiasi software.

Sintassi

2;10|result|"hello",!text_upper/1|s;12|$result

!nome/primitiva/arietà chiama una primitiva nativa. Gli argomenti sono sullo stack RPN.
