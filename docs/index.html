01 · IL LINGUAGGIO

General-purpose, senza perdere il DNA agentico.

AXL unisce normali primitive di programmazione a memoria, tool, agenti e workflow. Il compilatore resta deterministico: un modello AI può scrivere il codice, ma non serve per interpretarlo.

ƒ

Core tipizzato

Funzioni, parametri, ritorni, moduli, namespace, controllo di flusso e diagnostica statica.

A

Frontend

Lexer, parser, source span, resolver moduli e type-checker. Nessun effetto runtime.

  • Parsing deterministico
  • Diagnostica strutturata
  • Tipi e namespace
IR

AX-IR

Famiglia di rappresentazioni intermedie tipizzate, serializzabili e versionate.

  • AX-IR JSON 1.0/1.1
  • Future AX-HIR e AX-MIR
  • Compatibilità testata
R

Runtime Rust

VM, scheduler, capability, memoria e backend multipiattaforma ad alte prestazioni.

  • Native e WebAssembly
  • Rust/C ABI
  • Sandbox e budget

03 · AGENT RUNTIME

Gli agenti sono principal.
Non semplici funzioni.

Ogni agente opera con uno scope locale e capability dichiarate. Le azioni sensibili sono verificate prima dell'effetto, registrate nell'audit e limitate da budget.

01Deny-by-default

Nessun tool è disponibile implicitamente.

02Approval fail-closed

Solo il booleano esatto true autorizza.

03AM scoped memory

Memoria persistente isolata e host-controlled.

04Audit + budget

Decisioni ed esecuzione restano osservabili.
