Protocollo verificato

Un blocco non chiude le possibilità.

Il compilatore implementa tre elementi. Insieme separano l'intenzione dall'implementazione senza nascondere i punti di personalizzazione.

01

Capacity

Il contratto tipizzato: cosa deve poter fare il blocco.

02

Skill

L'implementazione nativa: per esempio una funzione Rust o un componente React.

03

Blueprint

Il grafo di porte, slot, hook e collegamenti controllati dal compilatore.

Ogni blueprint deve esporre almeno una superficie tra input, slot, hook, parametro, azione o policy. Stato, eventi ed errori completano la sua interfaccia osservabile.

Esempio compilato

Una riga CRM sostituibile.

La capacity definisce la forma. La skill collega React. Lo slot mantiene aperta la personalizzazione della UI.

parser verificato tipi verificati IR round-trip 
capacity CustomerRow
  op render Customer -> UI

skill DefaultCustomerRow provides CustomerRow
  native react crm::DefaultCustomerRow

blueprint CustomerList
  slot table.row: CustomerRow = DefaultCustomerRow
