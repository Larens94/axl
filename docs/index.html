01 / LANGUAGE

Less syntax.
More semantics.

AXL non imita linguaggi costruiti per essere letti dagli esseri umani. Usa frame numerici, campi delimitati ed espressioni RPN.

BIND + MATH10|x|#2,#3,#4,*,+|i

Typed binding. RPN removes precedence and parentheses.

FUNCTION40|add|a:i,b:i|i;11|$a,$b,+;99

Signature, body and return in one stream.

IMPORT1|m|m.axl;12|#20,#22,^m.add/2

Relative module, explicit namespace, postfix call.

MEMORY20|k|"v"|95|3600|r;12|@k

Scoped AM record with confidence, TTL and source.

GENERAL-PURPOSE

Compact does not mean limited.

AXL is designed to express backend, web, native apps, mobile, systems, graphics, GPU workloads, agents and workflows. The source stays stable while target bridges evolve.

02 / ARCHITECTURE

One source.
Any backend.

Rust è il primo runtime di basso livello, non un limite del linguaggio. AX-HIR, AX-MIR e ABI versionate separano semantica e piattaforma.

03 / EXECUTION

Power, bounded.

Un linguaggio per agenti deve poter fare qualsiasi cosa senza ricevere implicitamente accesso a tutto.

01

Deny by default

Tool e bridge esistono solo quando l'host li registra e l'agente li riceve.

02

Fail closed

Solo un'approvazione booleana esatta autorizza gli effetti sensibili.

03

Scoped memory

AM conserva valori tipizzati, metadata e TTL dentro scope controllati dall'host.

04

Budget + audit

Step, valori, output, tool e memoria sono limitati; le decisioni restano osservabili.

04 / START

Run the reference.

La reference Python fissa oggi la semantica. `pack` converte il frontend legacy nella forma compact canonica.

$ git clone https://github.com/Larens94/axl.git
$ cd axl && python3 -m pip install .
$ axl run examples/compact.axl
$ axl pack readable.axl -o canonical.axl
$ axl run canonical.axl
$ axl compile app.axl -o app.axlir.json
$ axl exec app.axlir.json
