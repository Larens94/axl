AXL 3.0 — Linguaggio Agent-Native

AXL è un linguaggio di programmazione per agenti che wrappa Rust e tutto quello che Rust può fare. Gli agenti combinano primitiva native per costruire qualsiasi software.

Cos'è AXL

  • Linguaggio agent-native — l'agente è la prima classe, non la funzione
  • 90+ primitiva native — ogni capability di Rust è esponibile
  • LLM integrato — reason, classify, extract, generate, embed sono native
  • Rust-backed — performance, sicurezza, portabilità

Esempio

2;10|result|"hello world",!text_upper/1|s;12|$result

→ "HELLO WORLD"

Primitiva Disponibili

  • I/O: file_read, file_write, file_exists, dir_list...
  • Text: text_upper, text_lower, text_split, text_find...
  • Collections: list_push, list_sort, map_get, map_set...
  • Math: math_add, math_mul, math_random...
  • Crypto: hash_sha256, encode_base64, crypto_random_bytes...
  • JSON: json_parse, json_stringify, json_validate...
  • Network: http_get, http_post...
  • System: env_get, time_now, path_join, process_run...

Avvio Rapido

cargo build --workspace
cargo run -p axl-cli -- run examples/compact.axl
cargo run -p netflix-server     # Netflix demo
cargo run -p ai-platform        # AI Platform demo
