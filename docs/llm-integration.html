Integrazione LLM

AXL 0.0.3 ha il reasoning LLM come primitiva nativa, non come tool esterno. Gli agenti possono ragionare, classificare, estrarre, e generare testo direttamente dal codice AXL.

Backend Trait

pub trait LlmBackend: Send + Sync {
    fn generate(&self, system: &str, messages: &[(String, String)]) -> Result<String, LlmError>;
    fn generate_stream(&self, system: &str, messages: &[(String, String)], on_chunk: &dyn Fn(&str) -> Result<(), LlmError>) -> Result<String, LlmError>;
    fn embed(&self, text: &str) -> Result<Vec<i64>, LlmError>;
    fn generate_json(&self, instruction: &str, input: &str, schema: &serde_json::Value) -> Result<serde_json::Value, LlmError>;
}

Primitiva LLM

Reasoning

# Chain-of-thought
10|result|"step by step",input,!llm_reason/2|s

Classification

# Classifica testo
10|category|"classify this",text,"news,opinion,tutorial",!llm_classify/3|s

Extraction

# Estrai entità
10|entities|"people, organizations",text,!llm_extract/2|s

Generation

# Genera testo
10|response|"system prompt",messages,!llm_generate/2|s

Embedding

# Genera embedding
10|embedding|"text to vector",!llm_embed/1|s
