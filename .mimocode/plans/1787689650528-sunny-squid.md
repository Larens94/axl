# Piano: Frontend React come Primitiva AXL

## Problema
Il frontend React è stato generato lanciando `cargo run -p axl-compiler` **manualmente** dal terminale. Questo viola la regola R6/AD11: tutto deve essere codice AXL, non Rust manuale. Se AXL non ha una capability, si aggiunge come primitiva nel core Rust e si chiama da AXL.

## Soluzione
Aggiungere `axl_compile_frontend` come primitiva AXL nel core Rust, così `app.axl` può generare il frontend React autonomamente.

**Dopo il fix, `app.axl` farà TUTTO:**
```
schema + seed → genera frontend React → avvia server REST
```

Nessun comando manuale, nessun file HTML scritto a mano.

---

## Step 1: Esposare `axl-compiler` come libreria

**File:** `runtime/axl-compiler/src/lib.rs` (NUOVO)

```rust
pub mod parser;
pub mod analyzer;
pub mod codegen;
```

**File:** `runtime/axl-compiler/src/main.rs`

Cambiare da `mod parser; mod analyzer; mod codegen;` a `use axl_compiler::{parser, analyzer, codegen};`

Questo rende il compiler importabile da altri crate (axl-core).

---

## Step 2: Aggiungere dipendenza `axl-compiler` in `axl-core-rs`

**File:** `runtime/axl-core-rs/Cargo.toml`

Aggiungere:
```toml
axl-compiler = { path = "../axl-compiler" }
```

---

## Step 3: Creare primitiva `axl_compile_frontend`

**File:** `runtime/axl-core-rs/src/primitives/compiler.rs` (NUOVO)

Funzione `axl_compile_frontend(args: &[Value]) -> Result<Value, PrimitiveError>`:
- `args[0]` = source path (string) — percorso al file .axl sorgente
- `args[1]` = output dir (string) — directory dove generare il frontend
- Internamente: `parser::parse_file()` → `analyzer::analyze()` → `codegen::react::generate()`
- Ritorna `Value::Bool(true)` su successo

---

## Step 4: Registrare la primitiva nel dispatch

**File:** `runtime/axl-core-rs/src/primitives/mod.rs`

- Aggiungere `pub mod compiler;` in cima
- Aggiungere match arm: `"axl_compile_frontend" => compiler::axl_compile_frontend(args).map_err(PrimitiveError),`
- Aggiungere a `available_primitives()`: `"axl_compile_frontend"`

---

## Step 5: Aggiornare `app.axl` per generare il frontend

**File:** `examples/crm/app.axl`

Dopo il seed dei dati, prima di `axl_server_start`, aggiungere:
```
10|_|"./examples/crm/crm.axl","./examples/crm/react",!axl_compile_frontend/2|s
```

Questo genera il frontend React dentro `examples/crm/react/` automaticamente.

---

## Step 6: Build e npm install automatici

Dopo `axl_compile_frontend`, aggiungere `process_run` per buildare il frontend:
```
10|_|"npm install && npm run build","./examples/crm/react",!process_run/2|s
```

Poi servire la directory `dist/` come static dir del server.

---

## Step 7: Pulizia

- Rimuovere `examples/crm/public/index.html` (vanilla HTML, non più necessario)
- Rimuovere `examples/crm/frontend/` (directory errata, duplicata)
- Aggiornare `app.axl` per servire `react/dist/` come static dir
