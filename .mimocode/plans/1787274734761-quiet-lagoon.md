# Piano: AXL Compiler → Rust + React (Confermato)

## Approccio

AXL è il **linguaggio sorgente**. Il compilatore genera:
1. **Codice Rust** (Axum + SeaORM + JWT + lettre)
2. **Codice React** (MUI + Refine)

## Stato Attuale

Il compilatore AXL è già implementato in `runtime/axl-compiler/`:
- Parser AXL → AST
- Analyzer → AnalyzedApp
- Codegen Rust → handlers, models, migrations
- Codegen React → pagine CRUD, App.tsx, package.json

### 2. Testare il Flusso Completo
```bash
# 1. Compila AXL → Rust + React
cargo run -p axl-compiler -- examples/crm/crm.axl generated

# 2. Build backend Rust
cd generated/backend && cargo build

# 3. Build frontend React
cd generated/frontend && npm install && npm run build

# 4. Deploy
cp -r generated/frontend/dist/* build/crm/
```
